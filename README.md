# SKC InfoPoint

A responsive, dark-themed information portal built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and curated resource links
- `style.css` — responsive design
- `script.js` — search, category filters, mobile navigation and current year

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required. Google Fonts are optional; the site has fallback fonts.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `skc-infopoint`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/(root)`, then save.
6. Wait for deployment, then open the URL shown in the Pages settings.

GitHub Pages hosts static HTML/CSS/JavaScript. This project does not use a backend or collect form submissions.

## Important
Links are curated starting points; destinations, eligibility, application windows and rules can change. Verify current details on the official destination website before submitting personal information or paying fees. SKC InfoPoint is an independent directory and is not an official government website.
