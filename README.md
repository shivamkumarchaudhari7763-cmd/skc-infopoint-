# SKC InfoPoint

A responsive Hindi information portal built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portal sections
- `style.css` — responsive styling for mobile and desktop
- `script.js` — search, category lists, mobile menu and official links
- `profile.png` — profile photo shown in the header

## Run locally
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Upload/replace `index.html`, `style.css`, and `script.js` in the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for GitHub Pages to finish deploying.

## Important
The listed entries are example directory links to official websites, not claims of current vacancies, results, deadlines, or live announcements. Verify details on the official department website before acting. SKC InfoPoint is an independent portal, not a government website.
